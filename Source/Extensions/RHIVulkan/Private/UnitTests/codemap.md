# Source/Extensions/RHIVulkan/Private/UnitTests/

## Responsibility
This folder contains unit tests for the RHIVulkan private implementation types and Vulkan backend logic. The tests validate frame graph construction, task graph processing, command buffer recording, memory allocation (TMemoryPool, TSlabHeap), descriptor set layout creation and caching, pipeline creation, descriptor set binding, image creation and layout transitions, buffer creation and memory allocation, ray tracing pipeline creation and shader binding table construction, and swapchain presentation flow. The tests ensure that Vulkan backend types function correctly and that the frame graph, task graph, and synchronization primitives operate as expected.

## Design
The unit tests are designed around the Arrange-Act-Assert pattern for each Vulkan type. Frame graph tests validate that FVulkanFrameGraph correctly constructs the dependency graph of TVulkanFrameTask<_Task> nodes and that the two-pass processing model (Pass1/Pass2) produces correct barrier and command ordering. Task graph tests verify that TVulkanTaskGraph<_Visitor> correctly tracks inputs/outputs and automatic attachment. Command buffer tests validate that FVulkanCommandBuffer correctly records commands and integrates task graph nodes via slab allocation. Memory allocation tests verify that TMemoryPool and TSlabHeap correctly allocate and deallocate memory blocks, including per-thread bucket caching and WAVL-tree free-block management. Descriptor set layout tests validate that FVulkanDescriptorSetLayout correctly creates layouts, handles hash-based deduplication, and supports partial binding. Pipeline tests validate that FVulkanGraphicsPipeline, FVulkanComputePipeline, and FVulkanRTPipeline correctly create Vulkan pipelines. Descriptor set binding tests verify that FPipelineResources.BindImage(), BindTexture(), BindBuffer(), and other methods correctly bind resources to pipelines. Image tests validate that FVulkanLocalImage and FVulkanSharedImage correctly create images, allocate memory, and manage layout transitions. Buffer tests validate that FVulkanLocalBuffer and FVulkanSharedBuffer correctly create buffers, allocate memory, and manage the bit-packed metadata layout. Ray tracing tests validate that FVulkanRayTracingShaderTable correctly builds the shader binding table and that the ray tracing pipeline creation and command execution operate correctly. Swapchain tests validate that FVulkanSwapchain correctly handles image acquisition, semaphore signaling, and vkQueuePresentKHR. All tests run against the Vulkan backend, ensuring that the frame graph, task graph, memory allocation, and presentation flow operate correctly.

## Flow
Test initialization creates Vulkan resource types and validates their creation through the private implementation. Frame graph tests validate the dependency graph construction and the two-pass processing model. Task graph tests verify input/output tracking and automatic attachment. Command buffer tests validate command recording and slab allocation. Memory allocation tests verify block allocation and deallocation patterns. Descriptor set layout tests validate layout creation and deduplication. Pipeline tests validate pipeline creation and resource binding. Image tests validate image creation, memory allocation, and layout transitions. Buffer tests validate buffer creation, memory allocation, and metadata layout. Ray tracing tests validate SBT construction and pipeline creation. Swapchain tests validate image acquisition, semaphore signaling, and presentation. Test teardown validates resource cleanup and destruction. All tests ensure cross-module consistency between the frame graph, task graph, memory allocation, descriptor sets, pipelines, images, buffers, and presentation.

## Integration
This folder tests the interfaces consumed by the entire Vulkan subsystem, particularly the frame graph (FVulkanFrameGraph), task graph (TVulkanTaskGraph<_Visitor>), command buffer (FVulkanCommandBuffer), memory allocator (TMemoryPool, TSlabHeap), descriptor sets (FVulkanDescriptorSetLayout), pipelines (FVulkanPipelineResources, FVulkanGraphicsPipeline, FVulkanRTPipeline), images (FVulkanLocalImage, FVulkanSharedBuffer), buffers (FVulkanLocalBuffer, FVulkanSharedBuffer), and swapchain (FVulkanSwapchain). Unit tests validate that the Vulkan backend types function correctly and that the frame graph, task graph, and synchronization primitives operate as expected across all subsystems. DX11 cross-coverage ensures the legacy code path remains functional alongside the Vulkan backend.
