# Source/Programs/ShaderToy/Public/Widgets/

## Responsibility
This directory exposes the ImGui widget definitions and UI component interfaces used by the ShaderToy shader playground. These widgets provide the interactive surface for shader editing, texture import, file browsing, and log viewing within the dockspace UI.

## Design
The widget definitions include `ImportTextureWidget` for loading and displaying input channel textures, `FileDialogWidget` for browsing and selecting shader source files and texture images, `MemoryUsageWidget` for displaying GPU and CPU memory statistics, and `LogViewerWidget` for rendering shader compilation error logs and trace output. Each widget follows the ImGui widget pattern: a state struct holding the current selection, file path, and preview data, and a render function that ImGui calls each frame. Widget IDs are defined as constexpr integers for consistency across dockspace rebuilds. State persistence is handled via `ImGuiSettingsHandler` for dockspace layout persistence across sessions. All widget APIs are designed to be stateless regarding the rendering pipeline; they read and display data without modifying the shader state directly.

## Flow
Each frame, the dockspace calls each widget's render function in sequence. `ImportTextureWidget` reads the current texture from the four input channels and displays a preview with file metadata. `FileDialogWidget` opens a system file picker on user interaction, allowing the developer to select a new shader source file or texture image; the selected path is stored in the widget state and passed to the shader source loader. `MemoryUsageWidget` queries the RHI for current GPU memory allocation and displays the information in a formatted table. `LogViewerWidget` displays the most recent compilation error log, scrolling to show new entries as they are appended. Widget state is updated based on user interaction, and the dockspace layout is persisted between sessions using ImGui's settings handler.

## Integration
The widget definitions are integrated into `Source/Programs/ShaderToy/Private/Widgets/` (`Source/Programs/ShaderToy/Private/Widgets/codemap.md`), which instantiates and renders each widget within the dockspace. The `ImportTextureWidget` interfaces with `Source/ContentPipeline/Texture/` (`Source/ContentPipeline/Texture/codemap.md`) to load and decompress texture assets for the four shader channels. `FileDialogWidget` source selections flow into the live shader recompilation pipeline, which interfaces with `Source/ContentPipeline/PipelineCompiler/` (`Source/ContentPipeline/PipelineCompiler/codemap.md`) for GLSL validation. The `LogViewerWidget` displays output from the same pipeline. The widget state and dockspace layout are shared across all ShaderToy instances via the `FModularDomain` lifecycle.
