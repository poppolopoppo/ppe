# Source/Programs/ShaderToy/Private/Widgets/

## Responsibility
This directory contains the private implementation of the ShaderToy ImGui widgets, including the rendering logic, state management, and user interaction handling for each dockspace component. These widgets are not exposed in the public header but are the core UI elements of the shader playground.

## Design
The private widget implementations follow the same API surface as the public widget definitions, but the internal state and rendering logic are encapsulated. `ImportTextureWidget` (`Private/Widgets` source) manages the texture slot selection, preview image generation, and file format detection for the four input channels. `FileDialogWidget` handles the ImGui file picker lifecycle, including path validation, texture loading, and error reporting for failed loads. `MemoryUsageWidget` queries the RHI's current memory allocation statistics and formats the output for display. `LogViewerWidget` maintains a circular buffer of the most recent compilation error logs, appending new entries as they are received from the shader compilation pipeline. Each widget stores its state in a static or module-scoped variable to persist across frames without requiring the main application to manage per-widget state.

## Flow
Each frame, the dockspace calls the render function for each widget. `ImportTextureWidget` reads the current texture from the four input channels, generates a small preview, and displays it alongside the file path and format information. If the user selects a new texture file via `FileDialogWidget`, the widget loads the image, updates the shader's input channel sampler, and refreshes the preview. `MemoryUsageWidget` queries the RHI for GPU memory allocation statistics and displays the total allocated, total available, and current usage percentage. `LogViewerWidget` appends new compilation error entries to its circular buffer and displays the buffer contents, scrolling to show the most recent errors. User interactions (button clicks, path selections) are handled within the widget render function and update the internal state accordingly.

## Integration
The private widgets are instantiated and rendered by `Source/Programs/ShaderToy/Private/` (`Source/Programs/ShaderToy/Private/codemap.md`), which creates the dockspace and registers each widget for each frame. The `ImportTextureWidget` interfaces with `Source/ContentPipeline/Texture/` (`Source/ContentPipeline/Texture/codemap.md`) for texture loading and format conversion. `FileDialogWidget` source selections flow into the live recompilation pipeline, which uses `Source/ContentPipeline/PipelineCompiler/` (`Source/ContentPipeline/PipelineCompiler/codemap.md`) for GLSL validation. The `LogViewerWidget` displays output from the same pipeline. Widget state changes propagate up through the main application loop, which coordinates with the `FModularDomain` for lifecycle events.
