# Source/Programs/ShaderToy/Private/

## Responsibility
This directory contains the private implementation of the ShaderToy shader playground, including the main application loop, ImGui dockspace management, live shader recompilation, and rendering pipeline. These components are the operational core of the live GLSL editor.

## Design
The private implementation centers on the main application class, which initializes the ImGui dockspace at startup and establishes the rendering frame graph. Each frame, the main loop updates shader uniform variables (`iTime`, `iMouse`, `iResolution`) and checks for source file modifications. If the fragment shader file has been modified since the last render, the live recompilation thread triggers a GLSL re-compilation via the internal pipeline, which parses the source, generates SPIR-V, and rebuilds the Vulkan shader module. Uniform buffers are updated with the latest input values before each render pass. The ImGui dockspace provides widgets for shader source editing, file dialog interactions, texture import from the four input channels, memory usage display, and a log viewer for compilation errors. A dummy checkerboard fallback is rendered when no shader is available or compilation has failed.

## Flow
The rendering flow begins at the main application loop, which processes OS messages and ImGui events. Each frame, uniform variables are updated (`iTime` increments monotonically, `iMouse` tracks cursor position in screen coordinates, `iResolution` reflects the current window size). The fragment shader source is read from disk; if the file modification time has changed since the last frame, the live recompilation thread triggers a re-compilation. The compiled shader output is rendered to the screen as a full-screen quad using the RHI frame graph. If live compilation fails, the error log is displayed via ImGui widgets and the checkerboard fallback is rendered. Input channels are sampled from loaded textures or memory buffers. The ImGui dockspace handles widget layout, including shader source import, file dialog interactions, texture memory usage display, and a log viewer for compilation errors.

## Integration
The private implementation integrates with `Source/Extensions/ApplicationUI/` (`Source/Extensions/ApplicationUI`) for module loading and remoting service support. The ImGui dockspace widgets provide interactions for texture import, which integrates with `Source/ContentPipeline/Texture/` (`Source/ContentPipeline/Texture/codemap.md`) for compression and format conversion. Live recompilation internally uses `Source/ContentPipeline/PipelineCompiler/` (`Source/ContentPipeline/PipelineCompiler/codemap.md`) for GLSL-to-SPIR-V translation. The main application class inherits from `FApplicationWindow`, sharing the same base as `Source/Programs/WindowTest/` (`Source/Programs/WindowTest/codemap.md`) and `Source/Programs/VoxelCube/` (`Source/Programs/VoxelCube/codemap.md`), and all three register with the `FModularDomain` for coordinated lifecycle management.
