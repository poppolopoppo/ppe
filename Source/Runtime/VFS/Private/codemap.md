# Source/Runtime/VFS/Private/

## Responsibility
The Private VFS folder implements the detail-level infrastructure underlying the public VFS API, containing the trie-based mount point registry detail, native filesystem component, and component base class not exposed in the public header hierarchy. This folder provides the concrete `FVirtualFileSystemTrie::` implementation, `FVirtualFileSystemNativeComponent::` native path mapping, and `FVirtualFileSystemComponent::` abstract base with protected constructor and pure virtual accessors. The design separates public interface (`Source/Runtime/VFS/Public/`) from private detail (`Source/Runtime/VFS/Private/`), enabling cross-platform native path mapping while isolating the trie data structure and component implementation details. `FVirtualFileSystem` singleton delegates to the trie for all mount point operations.

## Design
Key patterns include the trie-based registry pattern where `FVirtualFileSystemTrie` uses `ASSOCIATIVE_VECTORINSITU<FMountingPoint, PVirtualFileSystemComponent>` — a sorted vector map — for O(log n) lookup of mounting points to components, supporting efficient `Mount()`, `Unmount()`, `Lookup()`, `Enumerate()`, `Glob()`, and `Match()` operations; the component base pattern where `FVirtualFileSystemComponent` has a protected constructor taking `FDirpath alias` and pure virtual accessors `Readable()`, `Writable()`, `ReadWritable()` that derived implementations override; the native mapping pattern where `FVirtualFileSystemNativeComponent` maps a virtual alias to a native filesystem path (`FString` on Windows, `std::wstring` on POSIX) and implements all three component interfaces (`IVirtualFileSystemComponentReadable`, `IVirtualFileSystemComponentWritable`, `IVirtualFileSystemComponentReadWritable`); the standard mount points pattern where `FVFSModule` startup creates native components with well-known aliases (`DataDir`, `ProcessDir`, `SavedDir`, `SystemDir`, `TmpDir`, `UserDir`, `WorkingDir`) and mounts them via the trie; the thread safety pattern where `FReadWriteLock` protects trie modifications, allowing concurrent lookups and serialized mount/unmount operations. All private types are detail implementations not for direct client consumption.

## Flow
Trie initialization: `FVirtualFileSystemTrie` constructor creates an empty `_nodes` vector with `ASSOCIATIVE_VECTORINSITU` sorted-order semantics; mount operation: `Mount(alias, component)` → `_nodes.Insert(alias, component)` maintaining sorted order; lookup operation: `Lookup(filename)` → binary search on `_nodes` by `FMountingPoint` alias → returns `PVirtualFileSystemComponent` or null; file read: `OpenReadable(filename)` → `Lookup()` → `component->OpenReadable(filename)` → component reads from native path via `FVirtualFileSystemNativeComponent::Unalias()` conversion; enumerate: iterate `_nodes` vector from beginning to end, yielding `FMountingPoint` + component pairs; unmount: `Unmount(alias)` → `_nodes.Remove(alias)` maintaining sorted order; component creation: `FVFSModule::Startup()` creates `FVirtualFileSystemNativeComponent` instances with well-known aliases and mounts them; all trie modifications are protected by `FReadWriteLock` — shared lock for lookups, exclusive mount/unmount.

## Integration
Connects upward to `Source/Runtime/VFS/Public/` as all private types implement the interfaces exposed by public headers; `FVirtualFileSystemTrie::` private implementation satisfies the public `FVirtualFileSystemTrie` contract; `FVirtualFileSystemNativeComponent::` private implementation satisfies the public `FVirtualFileSystemNativeComponent` contract. Connects to `Source/Runtime/Serialize/` as `FTransactionSerializer` uses private `FVirtualFileSystem` detail classes for source file access during deserialization. Connects to `Source/Runtime/Remoting/` as custom endpoints may expose VFS file operations. Connects to `Source/Runtime/Network/` as HTTP endpoints may read configuration files from VFS. Real paths: `Source/Runtime/VFS/Public/VirtualFileSystemTrie.h`, `Source/Runtime/VFS/Public/VirtualFileSystemComponent.h`, `Source/Runtime/VFS/Public/VirtualFileSystemNativeComponent.h`, `Source/Runtime/VFS/Public/VirtualFileSystem.h`.
