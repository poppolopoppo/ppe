# Source/Runtime/Remoting/

## Responsibility
The Remoting folder owns the remoting service module, the `FRemotingServer` HTTP wrapper, and the full endpoint ecosystem including RTTI auto-exposure, OpenAPI/Swagger generation, and process management. The `FRemotingModule` singleton manages module lifecycle (`Start`, `Shutdown`, `DutyCycle`, `ReleaseMemory`) and owns the `FRemotingService` instance. `FRemotingServer` extends `FHttpServer` to register and route requests to configured `IRemotingEndpoint` instances. The folder provides auto-generated REST API coverage via `FRTTIEndpoint` (exposing the entire `FMetaDatabase` as JSON), OpenAPI 3.0 document generation via `FOpenAPI`, and Swagger UI serving via `FSwaggerEndpoint`. This is the primary integration point for exposing application functionality and reflection data over HTTP.

## Design
Key patterns include the `RTTI_MODULE_DECL(PPE_REMOTING_API, Remoting)` macro for module registration, the variant-based endpoint registry `std::variant<URemotingEndpoint, PBaseEndpoint>` in `FRemotingServer._endpoints` stored as `TThreadSafe<FEndpointMap, EThreadBarrier::RWLock>` with read-write lock synchronization, and the `FRemotingModule.StaticInfo` module info constant. `FRTTIEndpoint` mirrors the entire `FMetaDatabase` using `FRTTIClass`, `FRTTIEnum`, `FRTTIProperty`, `FRTTIFunction`, `FRTTIParameter`, `FRTTIModule`, `FRTTITransaction` mirror types, cached thread-safely by `FRTTITraitsCache` (HASHMAP). `FOpenAPI` builds the OpenAPI 3.0 document structurally via `DefineRTTIMetaClass()`, `Traits()`, and `DefineRTTISchemas()`, with schemas for traits, objects, operations, and parameters. `FSwaggerEndpoint` serves the Swagger UI HTML page and renders the OpenAPI spec. Module lifecycle: `FRemotingModule.Start()` → `FRemotingServer.Start()` → endpoint registration → `FHttpServer.Start(workers)` → `OnRequest` routing → `IRemotingEndpoint.EndpointProcess()`. The `FRemotingContext` per-request structure carries cookie/post/query maps, localhost address, endpoint enumerator, and a sync event for callback coordination.

## Flow
Bootstrap: `FRemotingModule.Get()` → `FRemotingModule.Start(domain)` → `FRemotingServer.Start()` → register default endpoints (`FRTTIEndpoint`, `FSwaggerEndpoint`) → `FHttpServer.Start(workerCount)` begins listening on `FAddress` localhost. Request cycle: `FHttpServer.OnRequest` → `FRemotingServer.Route()` → iterates `_endpoints` variant values → `IRemotingEndpoint.EndpointProcess(ctx)` → `EndpointDispatchIFP()` path/method routing → `PrivateEndpointProcess(ctx, relativePath)` or `PrivateEndpointOpenAPI(api)` dispatch → response serialization via `FOpenAPI`/`FJsonSerializer`. For `FRTTIEndpoint`: `EndpointProcess` dispatches to 6 operation categories (Traits, Objects, Transactions, Modules, Classes, Enums) by reading from `FMetaDatabase` and serializing via `FOpenAPI`. For `FSwaggerEndpoint`: `PrivateEndpointOpenAPI()` populates `FOpenAPI`; `PrivateEndpointProcess()` serves Swagger UI HTML. Tick: `FRemotingServer.Tick(dt)` processes pending `FRemotingCallback` events via `TThreadSafeEvent<FRemotingCallback, true>.Wait()`. Shutdown: `FRemotingModule.Shutdown()` → `FRemotingServer.Shutdown()` → `FHttpServer.Shutdown()` → unregister endpoints.

## Integration
Connects to `Source/Runtime/Network/` as `FRemotingServer` inherits `Network::FHttpServer`, uses `FHandShaker` for connection management, and `FRemotingContext` carries `Network::FAddress` localhost and `FRemotingCookieMap`/`FRemotingPostMap`/`FRemotingQueryMap`. Connects to `Source/Runtime/RTTI/` as `FRTTIEndpoint` reads entire `FMetaDatabase` (classes, enums, objects, transactions, modules) and exposes them via auto-generated REST API; responses serialized via `FOpenAPI` and `FJsonSerializer`; `FOpenAPI.DefineRTTIMetaClass()` traverses `FMetaClass` hierarchy. Connects to `Source/Runtime/VFS/` as custom endpoints may expose file system operations; `FOpenAPI` may reference VFS-mounted resources. Real paths: `Source/Runtime/Remoting/Public/RemotingModule.h`, `Source/Runtime/Remoting/Public/RemotingServer.h`, `Source/Runtime/Remoting/Public/RemotingEndpoint.h`, `Source/Runtime/Remoting/Public/Remoting/RTTIEndpoint.h`, `Source/Runtime/Remoting/Public/Remoting/OpenAPI.h`, `Source/Runtime/Remoting/Public/Remoting/SwaggerEndpoint.h`, `Source/Runtime/Remoting/Public/Remoting_fwd.h`. Neighbor paths: `Source/Runtime/Network/Public/Http/Server.h`, `Source/Runtime/RTTI/Public/RTTI/Module.h`, `Source/Runtime/RTTI/Public/MetaDatabase.h`, `Source/Runtime/VFS/Public/VirtualFileSystem.h`.
