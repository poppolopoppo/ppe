# Source/Runtime/Core/Public/Time/

## Responsibility
This folder implements the Engine's time and timestamp infrastructure, providing high-resolution timers, platform time queries, and timing utilities used across profiling, benchmarking, animation, and gameplay systems. It defines the time types, platform integration layers, and timing services that enable consistent time measurement across all platforms and subsystems.

## Design
Time design follows a platform-abstraction pattern with FPlatformTime as the central interface, concrete-ized by FGenericPlatformTime, FWindowsPlatformTime, and FLinuxPlatformTime. The core time type FTimestamp represents a point in time, and FDuration represents a time interval. The folder provides the FTimer class for scoped timing, FCounter and FTimer for high-resolution frequency-dependent timing, and FPlatformTime::Now() for current time queries. Time types are templated on the resolution source (performance counter, monotonic clock, system time) and support compile-time selection of the best available timer via Meta::TEnableIf and platform-specific traits. The FTickCounter type provides tick-based timing for gameplay timers, and FTicksPerSecond provides the conversion factor. All time types are designed for minimal overhead, with many operations inlineable and compile-time evaluable.

## Flow
Time querying flows through FPlatformTime::Now(), which resolves to the platform-specific implementation: QueryPerformanceCounter on Windows, clock_gettime(CLOCK_MONOTONIC) on Linux, or a fallback high-resolution timer. Timer start/stop: FTimer::Start() records the current timestamp; user code executes; FTimer::Stop() computes the delta as Now() - start. Counter operations: FCounter::Next() advances the counter by 1/Frequency seconds; FTimer::Elapsed() returns the accumulated duration. FTickCounter advances by tick intervals of 1/FTicksPerSecond seconds. When used in profiling, timestamps are recorded via FStackMarker at function entry/exit, and the data is flushed to FPlatformProfiler at shutdown. Benchmark timing: Benchmark::Start() records FPlatformTime::Now(); user code executes; Benchmark::Stop() computes delta and reports via FCounter. All time types integrate with the Memory smart pointer system if persistently allocated.

## Integration
Time/ is integrated across the entire Engine: Diagnostic/ FBenchmark and FCounter/FTimer use FPlatformTime for high-resolution timing. Maths/ TScalarVector and TScalarMatrix types may incorporate time-based interpolation and animation parameters. Thread/ FStackMarker uses FPlatformTime to record scope durations for profiling. IO/ FArchive serializes timestamp and duration data for saved games and state checkpoints. HAL/ PlatformTime provides the concrete implementation behind the FPlatformTime interface. Modular/ FModularServices may expose time-related services for module synchronization. Container/ TVector and TArray may store FTimestamp and FDuration values for animation tracks and gameplay timers. The primary header PlatformTime.h defines the FPlatformTime interface, and all time types are included in nearly every subsystem that requires timing or profiling data.
