# Source/Runtime/Core/Public/Maths/

## Responsibility
This folder implements the Engine's math types and spatial acceleration structures: TScalarVector, TScalarMatrix, TQuaternion, FTransform, TBoundingIntervalHierarchy (FBIH, TBIHTree, TBIHTraits), FOctree, TSHVector, TSHRotation, TSHFunctionProjector, SHSample, SHSampleCollection, TScalarBoundingBox, TScalarRectangle, TScalarMatrix, TScalarVector, TScalarRectangle, TScalarBoundingBox, TScalarVectorHelpers, TScalarMatrixHelpers, SHVector, SHVectorHelpers, SHVector_fwd, SHVector, SHRotation, SHSample, SHSampleCollection, SHFunctionProjector, PackedVectors, Plane, Ray, Sphere, Frustum, BoundingBox, Units, RandomGenerator, and EigenMatrixSolver. Scalar vector/matrix templates are parameterized on dimension and type, providing compile-time size safety. Quaternion and FTransform represent 3D rotations and affine transforms. BIH and Octree structures enable fast spatial queries. SH vector types support spherical harmonics for lighting and ambient occlusion. RandomGenerator provides deterministic and stochastic RNG. EigenMatrixSolver solves linear systems for physics and rendering.

## Design
Math types are template-heavy and compile-time dimensioned: TScalarVector<T, Dim> and TScalarMatrix<T, Rows, Cols> use static_assert to enforce dimension consistency at compile time. TQuaternion stores four floats (x,y,z,w) with normalized-unit invariants; FTransform combines translation, rotation (quaternion), and scale into a 4x4 matrix. BIH structures (FBIHNode, TBIHTree) use bounding box hierarchies for ray-tracing and spatial partitioning, with TBIHTraits specializing for FBoundingBox and FSphere. Octree (FOctree) recursively subdivides space into eight children, ideal for scene management. SH types (TSHVector<Degree>, TSHRotation, TSHFunctionProjector) are templated on band count degree, enabling compile-time SH band selection. PackedVectors half-precision types reduce memory bandwidth. Units<T,R> provides compile-time dimensional analysis (meters, seconds, radians) preventing unit mismatches. RandomGenerator supports MT19937, Xorshift, and LCG backends with thread-local state. EigenMatrixSolver wraps Eigen for linear algebra solvers (inverse, LU, QR).

## Flow
Math type construction uses default initializers (zero for scalars, identity for matrices, unit quaternion for rotations). Mathematical operations (Add, Subtract, Multiply, Dot, Cross) produce new values without mutating operands unless the InPlace variant is called. Spatial queries: TBIHTree::IntersectRay tests ray against BIH nodes recursively; FOctree::Contains tests point containment recursively; Frustum::Contains tests against planes. SH coefficient computation: TSHFunctionProjector::Project evaluates basis functions over sample directions. Random variate generation: RandomGenerator::NextFloat/NextInt produce values in [0,1) or specified ranges. Unit-aware operations: TScalarVector:: operator+ respects dimensional consistency (meters + meters, not meters + seconds). Eigen solver flow: factorization -> back-substitution -> solution vector. Post-solve normalization: quaternions are renormalized after interpolation.

## Integration
Maths types are the numeric foundation used by every other subsystem. Container/ TVector<T> and TArray<T> store TScalarVector and TScalarMatrix instances. Allocator/ FTrackingAllocator provides memory for matrix coefficient data. Thread/ FThreadContext stores SIMD register state aligned to CACHELINE_ALIGNED. IO/ FFormat uses TScalar types for formatting precision. Diagnostic/ FBenchmark measures math operation throughput via FPlatformTime. IO/ FArchive serializes TQuaternion, FTransform, TScalarVector, TScalarMatrix elements. Maths/ EigenMatrixSolver solves linear systems used by Physics/ FBodyInstance and Rendering/ FSceneProxy. Maths/ SHVector/ SHRotation coefficients feed into Rendering/ FLightingSceneProxy for SH irradiance baking. Maths/ BoundingBox/ Frustum feed into Rendering/ FCullingScene for view culling. HAL/ PlatformMaths provides SIMD intrinsics lowered by SSEHelpers for math ops.
