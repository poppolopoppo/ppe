## Responsibility
This folder implements public MeshBuilder components, exposing the mesh content pipeline's primary API surface for other modules and tools to consume. It provides the type-safe mesh operations, import interfaces, and build graph node types that serve as the main entry point for mesh-related content pipeline functionality across the entire codebase.

## Design
Key patterns center on `FMeshBuilderModule` as the module interface, with `IContentImporter` as the public base importer interface and `TContentImporter<_Import>` templated importers providing type-safe mesh format import. `FContentImporterContext` is publicly available for source-to-destination mesh mapping. `FContentPipelineNode` serves as the RTTI-enabled base type for public mesh pipeline nodes, integrating with `FBuildGraph::AddNode()` and `FBuildGraph::AppendNodes()` for DAG management. The design follows the established template-based type-safe pattern with `META_DYNAMIC_CASTABLE_IMPL` for dynamic type resolution, and leverages `FBuildEnvironment` for platform, cache, and executor services. Module registration uses `RTTI_MODULE_DECL` for RTTI integration with the FModularDomain system.

## Flow
Module startup calls `FMeshBuilderModule::Start()` which registers importer services with the modular domain. Public consumers initiate mesh import via `IContentImporter::Import(ctx, dst)`, dynamically casting to the appropriate `TContentImporter<_Import>`. Build graph execution follows `FBuildGraph::ScanAll()` → `FScanContext::Scan()` → `node.Scan()` for dependency registration, then `FBuildContext::Build()` → `node.Import()` → `node.Process()` for mesh data processing. Output mesh files are tracked via `FBuildGraph::AddFiles()`. Module shutdown calls `FMeshBuilderModule::Shutdown()` and `FMeshBuilderModule::ReleaseMemory()` for cleanup.

## Integration
Integrates with `Source/ContentPipeline/MeshBuilder/Private/Mesh/` and `Source/ContentPipeline/MeshBuilder/Public/Mesh/Format` for private mesh implementation, `Source/ContentPipeline/Asset.Geometry/Private/` and `Source/ContentPipeline/Asset.Geometry/Public/` for geometry data, `Source/ContentPipeline/BuildGraph/Private/` and `Source/ContentPipeline/BuildGraph/Public/` for graph execution, and `Source/ContentPipeline/PipelineCompiler/Private/Vulkan/Pipeline/` and `Source/ContentPipeline/PipelineCompiler/Public/Vulkan/Pipeline/` for Vulkan mesh pipeline compilation. Also connects to `Source/Programs/BuildRobot/` for headless build automation.
