# Source/ContentPipeline/Asset/Public/

## Responsibility
The Asset/Public folder exposes the public API surface for the ContentPipeline Asset library, declaring the abstract toolchain interface FAbstractContentToolchain, the concrete TContentToolchain implementation, template-based importer and processor types TContentImporter<_Import> and TContentProcessor<_Process>, and the three context types FContentImporterContext, FContentProcessorContext, and FContentSerializerContext that inject source directories, dependency lists, and intermediate output paths into the toolchain execution flow. It also defines FContentImporterException for type mismatch guards and the META_DYNAMIC_CASTABLE_IMPL macros enabling runtime type dispatch. The public headers are designed for consumption by downstream modules and other ContentPipeline subsystems without requiring access to implementation details.

## Design
The public API follows a template-based design pattern for type-safe importers and processors, with META_DYNAMIC_CASTABLE_IMPL enabling runtime type identification and dynamic casting. FAbstractContentToolchain declares the pure virtual interface (Initialize, Import, Process, Serialize, Clean) while TContentToolchain provides the concrete DAG-driven execution implementing all five stages. The three context types are fully defined in the public headers: FContentImporterContext carries source directory and dependency list, FContentProcessorContext adds intermediate output path information, and FContentSerializerContext handles final artifact output parameters. Exception specifications use FContentImporterException for type mismatch errors. All public types are RTTI-enabled via the META_DYNAMIC_CASTABLE_IMPL macro, facilitating cross-module type resolution. The folder deliberately omits implementation details such as concrete importer specializations and serializer logic, which reside in the Private subfolder.

## Flow
Downstream modules consume the public API by instantiating TContentToolchain and calling Initialize() to register asset types, followed by Import() to dispatch source assets to the appropriate IContentImporter::Import(ctx, dst), Process() to transform intermediate data via IContentProcessor::Process(ctx, dst), Serialize() to produce persistent asset artifacts via IContentSerializer::Serialize(ctx, dst), and Clean() for resource reclamation. The context injection system provides all necessary path information (source dirs, dependency lists, intermediate output dirs) through the three context types. Type-safe dispatch occurs via dynamic cast from the templated importer/procesor bases to concrete specializations. The public API headers are included by Source/ContentPipeline/Asset/Private/ for the concrete implementations, and by Source/ContentPipeline/BuildGraph/ for DAG node registration, and by Source/ContentPipeline/MeshBuilder/Public for mesh importer integration.

## Integration
Asset/Public integrates with Source/ContentPipeline/Asset/Private/ which contains the concrete importer and processor specializations, with Source/ContentPipeline/BuildGraph/ for DAG-based build node tracking where asset build nodes are registered using the public API types, with Source/ContentPipeline/MeshBuilder/Public for mesh importer integration where mesh importers depend on the template-based importer framework, with Source/ContentPipeline/Texture/ for texture processor coordination where texture processing types are registered through the public API, with Source/ContentPipeline/PipelineCompiler/ for compiled shader output handling where compiled pipeline outputs may be referenced as asset artifacts, and with Source/ContentPipeline/Asset.Geometry/ for geometry asset type specialization. Specific paths include Source/ContentPipeline/Asset/Public/ headers included by Source/ContentPipeline/Asset/Private/ for concrete types, Source/ContentPipeline/BuildGraph/ for node registration using FBuildNode subtypes, Source/ContentPipeline/MeshBuilder/Public/Mesh for mesh format importer dependencies, and Source/ContentPipeline/Asset.Geometry/Public for geometry type registration.
