## Responsibility
This folder implements public Texture components for the Texture submodule, exposing the texture content pipeline's primary API surface for other modules and tools to consume. It provides type-safe texture operations and data types that serve as the main entry point for texture-related functionality across the entire Codebase.

## Design
Key patterns center on `FTextureSource` as the publicly available texture data + metadata type, with `FTextureSourceProperties` publicly exposing dimensions, format, gamma, and flags. The design leverages `IContentProcessor` as the public processor interface with `TContentProcessor` templated type-safe processing for texture operations. Compression follows the established block-compression pattern (DXT1/DXT5) with color mask detection (RGB→DXT1, RGBA→DXT5) publicly accessible. `FCompressedImage` provides the public compressed image type. Mip chain validation via `HasFullMipChain2D()` is publicly available. HDR and LongLat cubemap detection support specialized public texture workflows. The design follows the established template-based type-safe pattern with `META_DYNAMIC_CASTABLE_IMPL` for dynamic type resolution, and leverages `FBuildEnvironment` for platform, cache, and executor services. Module registration uses `RTTI_MODULE_DECL` for integration with the FModularDomain system.

## Flow
Public consumers access texture operations through the `FTextureSource` type, which provides data and metadata. Texture processing is initiated via `IContentProcessor::Process(ctx, dst)`, dynamically casting to `TContentProcessor` for type-specific processing. The pipeline flows: image processing → compression (DXT1/DXT5 with color mask detection) → mip chain generation (validated via `HasFullMipChain2D()`) → output registration via `FBuildEnvironment::AddFiles()`. Module shutdown and cleanup follow the established three-phase pattern with `FCleanContext::Clean()`.

## Integration
Integrates with `Source/ContentPipeline/Texture/Private/Texture/` for private texture implementation, `Source/ContentPipeline/MeshBuilder/Public/Mesh/` for mesh-associated texture workflows, `Source/ContentPipeline/PipelineCompiler/Public/Vulkan/Pipeline/` for Vulkan texture backend integration, and `Source/ContentPipeline/BuildGraph/Public/` for graph execution orchestration. Also connects to `Source/Programs/BuildRobot/` for headless build automation and `Source/Programs/UnitTest/` for texture compression test validation.
