## Responsibility
This folder implements public PipelineCompiler components, exposing the pipeline compiler's primary API surface for other modules and tools to consume. It provides type-safe compiler interfaces and pipeline compilation capabilities that serve as the main entry point for all pipeline type compilation workflows across the ContentPipeline subsystem.

## Design
Key patterns center on `IPipelineCompiler` as the public compiler abstraction interface, with `FVulkanPipelineCompiler` as the concrete Vulkan backend type. `FVulkanSpirvCompiler` public operations handle GLSL → SPIR-V compilation. Pipeline descriptor types (`FMeshPipelineDesc`, `FGraphicsPipelineDesc`, `FComputePipelineDesc`, `FRayTracingPipelineDesc`) are publicly available for pipeline configuration. The design leverages `FVulkanDebuggableShaderModule` for debug/profiling/trace support across all pipeline types. Specialization constants for task/mesh group sizes and local group sizes are handled uniformly through the public interface. Format negotiation via `HighestPriorityShaderFormat_()` selects the best available format from supported options. Module registration uses `RTTI_MODULE_DECL` for integration with the FModularDomain system.

## Flow
Public consumers initiate pipeline compilation by calling `IPipelineCompiler::Compile()` with a pipeline descriptor and format configuration. The call dispatches to the appropriate backend implementation. The compiled pipeline descriptor is used for shader module creation and pipeline layout generation. Reflection data extracted during compilation is made available through public interfaces. Output pipeline objects and shader modules are tracked via `FBuildEnvironment::AddFiles()` for downstream consumption. Module shutdown and cleanup follow the established three-phase pattern.

## Integration
Integrates with `Source/ContentPipeline/PipelineCompiler/Private/Vulkan/Pipeline/` and `Source/ContentPipeline/PipelineCompiler/Private/Vulkan/` for private Vulkan pipeline compilation details, `Source/ContentPipeline/BuildGraph/Private/` and `Source/ContentPipeline/BuildGraph/Public/` for build graph orchestration of pipeline compilation, `Source/ContentPipeline/MeshBuilder/Private/` and `Source/ContentPipeline/MeshBuilder/Public/` for mesh data input, and `Source/ContentPipeline/Asset.Texture/Private/` and `Source/ContentPipeline/Asset.Texture/Public/` for texture-related pipeline compilation. Also connects to `Source/Programs/BuildRobot/` for headless compilation workflows and `Source/Programs/WindowTest/Private/Compiler/` for compiler validation tests.
