## Responsibility
This folder implements private Vulkan pipeline compiler components for the Vulkan/Pipeline submodule, handling Vulkan shader compilation, pipeline layout generation, and SPIR-V reflection for all pipeline types (graphics, compute, ray tracing). It serves as the core backend for translating GLSL source into Vulkan-compatible shader modules and pipeline descriptors.

## Design
Key patterns center on `FVulkanPipelineCompiler` as the primary compiler backend, with `IPipelineCompiler` as the abstraction interface. `FVulkanSpirvCompiler` handles GLSL → SPIR-V compilation via `ParseGLSL_()` → `CompileSPIRV_()` → `BuildReflection_()` → `ParseAnnotations_()`. Pipeline descriptors use `FMeshPipelineDesc`, `FGraphicsPipelineDesc`, and `FComputePipelineDesc` for graphics, compute, and compute pipeline configuration respectively. `FRayTracingPipelineDesc` supports ray tracing pipeline creation. Shader module creation uses `CreateVulkanShader_()` with `VkShaderModule` caching for performance. `FRayTracingDebuggableShaderModule` provides debug/profiling/trace capabilities. Format negotiation is handled by `HighestPriorityShaderFormat_()` which selects the best available format from supported options.

## Flow
Compile entry: `FVulkanPipelineCompiler::Compile(desc, fmt, logger)` is called for each pipeline type, dispatching to the appropriate compiler backend. GLSL source parsing flows through `ParseGLSL_()` → `CompileSPIRV_()` → `BuildReflection_()` → `ParseAnnotations_()` for SPIR-V generation and reflection data extraction. Pipeline layout merges descriptor sets from all shader stages via `MergePipelineResources_()`. Shader modules are created with `CreateVulkanShader_()`, which handles `VkShaderModule` creation and caching. Specialization constants for task/mesh group sizes and local group sizes are applied during compilation. Debug/profiling/trace support is enabled via `FRayTracingDebuggableShaderModule`.

## Integration
Integrates with `Source/ContentPipeline/BuildGraph/Private/` and `Source/ContentPipeline/BuildGraph/Public/` for build graph orchestration of pipeline compilation, `Source/ContentPipeline/MeshBuilder/Private/` and `Source/ContentPipeline/MeshBuilder/Public/` for mesh data to compile, and `Source/ContentPipeline/Asset.Texture/Private/` and `Source/ContentPipeline/Asset.Texture/Public/` for texture-associated pipeline compilation. Downstream consumers include `*.cpp` test files and `Source/Programs/BuildRobot/` for headless compilation workflows.
